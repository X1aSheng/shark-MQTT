1. Check the status:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "shark-mqtt.name" . }}

2. Port forward for local testing:
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "shark-mqtt.fullname" . }} 18983:18983 18999:18999

3. Test with an MQTT client:
   mqttui --broker localhost:18983

4. Check metrics:
   curl http://localhost:18999/metrics
   curl http://localhost:18999/healthz
   curl http://localhost:18999/readyz

{{- if gt (int .Values.replicaCount) 1 }}

WARNING: replicaCount={{ .Values.replicaCount }} but shark-mqtt is NOT a cluster.
Each replica is an independent broker that shares no session, subscription or
retained state with the others, so messages published to one pod are never
delivered to subscribers on another, and the retained store diverges per pod.
Set replicaCount=1 (and autoscaling.enabled=false) unless a clustering /
topic-routing layer is in front. See the chart README, "多副本 != 集群".
{{- end }}

{{- if .Values.autoscaling.enabled }}
{{- if gt (int .Values.autoscaling.maxReplicas) 1 }}

WARNING: autoscaling is enabled with maxReplicas={{ .Values.autoscaling.maxReplicas }}.
An HPA scales a non-clustered broker into independent replicas that silently
lose messages, and it cannot rebalance the long-lived TCP connections already
accepted. Disable it unless a clustering / topic-routing layer is in place.
{{- end }}
{{- end }}
